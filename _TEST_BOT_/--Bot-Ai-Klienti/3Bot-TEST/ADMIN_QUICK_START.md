## ⚡ Самый быстрый способ

### Шаг 1: Открыть AI чат
Открой Claude или ChatGPT в браузере/приложении

### Шаг 2: Копируй этот текст в чат

```
Скопируй весь текст из файла:
_TEST_BOT_/--Bot-Ai-Klienti/3Bot-TEST/ORCHESTRATOR_PROMPT.md
и вставь в этот чат
```

### Шаг 3: Выполни эту команду

Напиши в чат **одну из этих команд**:

#### Вариант 1: Автоматический выбор (рекомендуется)
```
Запускай агентів для сбору даних
```
→ AI сам выберет следующий непройденный сценарий

#### Вариант 2: Конкретный сценарий
```
Запускай сесію 1
```
или
```
Запускай сесію 3 — пишем в поддержку
```

#### Вариант 3: Произвольная задача
```
Усі боти тестують фото — загружають, видаляють, шукають помилки
```

## 🤖 Что произойдет после команды?

1. **AI будет писать пошаговые инструкции** для каждого бота
   - Какой экран открыть
   - Что нажать
   - Какой текст написать
   - Что ждать в результате

2. **Ты следишь за процессом** (смотришь в чат, что пишет AI)

3. **AI собирает результаты** и пишет в конце:
   - ✅ Сколько действий успешно выполнено
   - ❌ Сколько ошибок найдено
   - 💥 Были ли крахи приложения
   - 📝 Какие баги найдены (список с приоритетами)
   - 💬 Какие замечания оставили боты по UX

## 💡 Советы для админа

### Когда запускать сессии?

- **После каждого нового билда APK** — убедиться что ничего не сломалось
- **Когда добавил новую фичу** — проверить что она работает со всеми типами заявок
- **Когда исправил баг** — запустить ту же сессию, убедиться что исправилось
- **Каждый день/неделю** — для общего здоровья приложения

### Как часто?

- **Минимум:** После каждого большого изменения
- **Оптимально:** Один раз в день (5-10 минут для быстрой сессии)
- **Для нагрузочного теста:** Когда хочешь проверить Firebase (сессия 10)

### Сколько времени?

- Одна сессия: **10-15 минут** (в зависимости от номера)
- Полный цикл (все 10): **2-3 часа** (можно делать несколько сессий в день)

## ❓ Частые вопросы админа

### Q: Что если AI не может запустить сессию?
**A:** Проверь:
1. Все ли эмуляторы/телефоны включены?
2. Установлено ли приложение (APK)?
3. Успешно ли могут залогиниться боты? (попробуй вручную залогиниться одним ботом)

### Q: Как мне прочитать полный отчет?
**A:** После выполнения сессии AI напишет его в чат. Можно:
- Копировать в текстовый файл
- Сохранить скриншот
- Копировать в Notion/Confluence

### Q: Что если найден критический баг?
**A:**
1. Отмети его как CRITICAL в отчете
2. Создай Issue в GitHub
3. Напиши шаги воспроизведения
4. Приложи скриншот из отчета

### Q: Можно ли запустить свой кастомный тест?
**A:** Да! Просто напиши что тебе нужно:
```
Усі боти тестують входити з разними мовами і перевіряють переводи
```
AI создаст сценарий на лету.

## 🚀 Готово к работе?

### Чек-лист перед первой сессией:

- [ ] Скачал/собрал последний APK
- [ ] Установил APK на эмуляторы/телефоны
- [ ] Попробовал залогиниться одним ботом вручную (убедиться что работает)
- [ ] Скопировал `ORCHESTRATOR_PROMPT.md` в буфер обмена
- [ ] Открыл новый чат в Claude/ChatGPT
- [ ] Вставил промпт в чат
- [ ] Написал первую команду: `Запускай сесію 1`

### Первый запуск может показать ошибки — это нормально!

Обычно:
- Неверные координаты элементов
- APK нужно переустановить
- Firebase Rules нужно обновить

Первую сессию часто запускают 2-3 раза, дебажат, потом уже работает как часы.
