# Инструкция: Как использовать боты Chaika Life

**Быстрый старт для тестирования системы заявок**

---

## 1. Вход в приложение

### Способ 1: Эмулятор Android (рекомендуется)

```bash
# Собрать и запустить приложение на эмуляторе
npm run android
# или
eas build --platform android --local
```

### Способ 2: Физический телефон

- Скачать APK файл
- Установить на Android устройство
- Запустить Chaika Life

1. Нажать **"Вход по email"** (или найти соответствующий пункт)

## 3. Что видно после входа

### Главный экран (Головний екран)

- Ленту заявок (requests feed)
- Фильтры по категориям
- Кнопка создания новой заявки (+)

### Навигация

Внизу экрана (bottom navigation):
- **Головна** — главная лента
- **Заявки** — история своих заявок
- **Чат** (или **Onlain-Chat**) — обсуждения
- **Профіль** — профиль пользователя

## 3.5. Обязательная подготовка профиля перед заявками

Перед созданием первой заявки каждый бот обязан пройти профиль через UI. Это блокирующий шаг: если аватар, возраст или пол не заполнены, заявку не создавать.

Путь:

```text
Профіль → Редагувати профіль → Тимчасовий аватар → выбрать аватар → указать возраст → указать пол → Зберегти
```

Если после входа приложение само открыло экран настройки профиля, заполняй его сразу. Не закрывай и не обходи этот экран.

## 4. Создание заявки (тестирование системы)

### Пошагово:

1. Убедиться, что выполнен раздел 3.5: профиль сохранён с временным аватаром, возрастом и полом.
2. На главной ленте нажать кнопку **"+"** или **"Додати"** (Добавить)
3. Выбрать **категорию** из списка:
   - **Проблемы** (Problemy)
   - **Помощь** (Pomoch)
   - **Куплю-продам** (Kuplu-Prodam)
   - **Потеряно-найдено** (Kto-Poteryal)
   - **Работа** (Poisk-Raboty)
   - **Места Чайки** (Mesta-Chayki)
   - И другие...

4. Заполнить форму заявки:
   - **Название** (обязательно)
   - **Описание** (обязательно)
   - **Фото** (опционально)

5. Нажать **"Опубліковать"** (Publish)

## 6. Многопользовательское тестирование

### Сценарий 1: Боты отвечают друг на друга

1. **Бот A (Matteo — электрик):**
   - Логинится
   - Создает заявку в категории "Проблемы": "Мастер готов чинить электричество, услуга платная"

2. **Бот B (Luca — логист):**
   - Логинится
   - Читает ленту
   - Находит заявку от Matteo
   - Нажимает "Ответить" или "Контакты"
   - Видит профиль и телефон: +380671000003

### Сценарий 2: Система модерации

1. Несколько ботов создают заявки
2. Проверить в **Admin Panel**, что заявки:
   - Попадают в модерацию
   - Одобряются
   - Появляются в ленте

### Сценарий 3: История заявок

1. Бот создает заявку
2. Нажать на вкладку **"Заявки"** (History)
3. Увидеть список:
   - Активные заявки
   - Завершённые заявки
   - Статус каждой

## 7. Проверка в Admin Panel

Если нужна административная панель:

```bash
cd admin-panel
npm install
npm run dev
```

Затем в браузере: `http://localhost:5173`

### Что проверять в админ-панели:

- **Заявки** — все заявки от ботов
- **Модерация фото** — если боты добавляют фото
- **Пользователи** — статус регистрации ботов
- **Статистика** — активность ботов

## 9. Типичные сценарии тестирования

### Сценарий A: Проверка категорий

```
1. Logg in as Luca
2. Create request in "Help" → system accepts
3. Log in as Matteo
4. Create request in "Problems" → system accepts
5. Check both appear in feed
```

### Сценарий B: Проверка чата

```
1. Log in as Bot 1 → Create request "Need help with X"
2. Log in as Bot 2 → Find request in feed
3. Tap "Reply" or "Contact" → Open chat
4. Send message
5. Switch to Bot 1 → Check message received
```

### Сценарий C: Проверка профилей

```
1. Log in as Bot 1
2. Go to Profile → Verify avatar, name, profession
3. Go to another bot's profile (from feed) → Check visibility
4. Verify phone number visible to other bots
```

### Сценарий D: Нагрузочный тест

```
1. Открыть 2 эмулятора/телефона
2. На каждом логинить разного бота
3. Одновременно создавать заявки
4. Проверить, что система не падает
```

## 11. Контакты и поддержка

Если возникают проблемы:

1. **Firebase Auth не работает** → проверить service account ключ
2. **Боты не видят заявки** → проверить `invite_access` статус в RTDB
3. **Аватарки не отображаются** → проверить `startAvatarKey` значение
4. **Приложение падает** → смотреть логи в Developer Console
