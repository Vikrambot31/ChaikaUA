## 1. Цель проекта

Создать систему из **10 AI-управляемых тест-ботов**, которые имитируют реальных пользователей приложения ChaikaUA. Боты используют приложение через USB-отладку (adb), выполняют сценарии взаимодействия, собирают ошибки и отправляют отчёты. Боты **не имеют доступа к коду** — они работают исключительно через UI приложения как обычные пользователи.

## 4. Технический стек управления

### 4.1. Инфраструктура эмуляторов

```bash
# Создание 10 эмуляторов Android (API 33)
for i in $(seq 1 10); do
  avdmanager create avd -n "TestBot_$i" -k "system-images;android-33;google_apis;x86_64" -d "pixel_4"
done

# Запуск с разными портами
for i in $(seq 1 10); do
  PORT=$((5554 + ($i - 1) * 2))
  emulator -avd "TestBot_$i" -port $PORT -no-window -no-audio &
done
```

### 4.2. Управление через adb

```bash
adb devices                                          # Список устройств
adb -s emulator-5554 shell input tap 540 960         # Тап
adb -s emulator-5554 shell input text "Привіт"       # Ввод текста
adb -s emulator-5554 shell screencap /sdcard/s.png   # Скриншот
adb -s emulator-5554 pull /sdcard/s.png ./bot1.png   # Получить файл
adb -s emulator-5554 shell uiautomator dump          # UI-дерево (XML)
```

### 4.3. Appium (альтернатива adb)

```javascript
const { remote } = require('webdriverio');
async function createBotSession(botIndex) {
  const port = 5554 + (botIndex - 1) * 2;
  return remote({
    hostname: 'localhost', port: 4723,
    capabilities: {
      platformName: 'Android',
      'appium:deviceName': `emulator-${port}`,
      'appium:app': './app-release.apk',
      'appium:automationName': 'UiAutomator2'
    }
  });
}
```

### 4.4. Распознавание экрана

AI-исполнитель анализирует экран двумя способами:
1. **Скриншот → Vision AI** — отправка PNG в модель с vision
2. **UI Automator dump → XML** — структура всех элементов с координатами

## 6. Протокол сбора ошибок

### Лог каждого действия (JSONL)

```json
{
  "session_id": "2026-06-06_session1",
  "bot_name": "Luca Moretti",
  "uid": "24h7Iz6ayzgeD73VkCKrIcGnXJ73",
  "timestamp": "2026-06-06T14:30:00Z",
  "action": "create_request",
  "screen": "Forma-Zayavki",
  "status": "success",
  "details": "Заявка створена",
  "error_message": null,
  "duration_ms": 3400
}
```

### Типы ошибок

| Тип | Описание | Приоритет |
|-----|----------|-----------|
| `crash` | Приложение вылетело | CRITICAL |
| `error_dialog` | Alert/Modal с ошибкой | HIGH |
| `blocked` | Кнопка неактивна / экран не загрузился | HIGH |
| `unexpected_state` | Экран не тот | MEDIUM |
| `slow_response` | > 5 сек | LOW |
| `ui_glitch` | Визуальный баг | LOW |
| `data_missing` | Данные не появились | MEDIUM |

### Автотикет в поддержку при HIGH/CRITICAL

```
Категорія: bug_report
Від: [ім'я бота]
Текст: "[TestBot] Помилка на екрані Forma-Zayavki:
  Дія: натискання 'Опублікувати'
  Очікування: перехід на підтвердження
  Результат: Alert 'Помилка завантаження фото'"
```

## 12. Безопасность

- Боты НЕ меняют код, НЕ пишут напрямую в Firebase, НЕ имеют модераторских прав
- Все тестовые заявки помечать префиксом `[TEST]`
- Между действиями пауза 2-5 сек (имитация реального пользователя)
- Firebase RTDB: 100 одновременных подключений — не превышать
