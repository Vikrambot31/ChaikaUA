# 🚀 Как запустить ИИ-агента

## Быстрый старт (30 сек)

### Шаг 1: Запусти админ-панель
```bash
cd C:\ChaikaUA\mobile-app-short
npm run dev --prefix admin-panel
```
Панель откроется на `http://localhost:5174`

### Шаг 2: Залогинься через Google
На экране входа кликни **"Войти через Google"** и авторизуйся своим аккаунтом

### Шаг 3: Скопируй промт агента
Открой файл: `AGENT_PROMPT.md` (в этой папке)

**Скопируй весь текст** промта

### Шаг 4: Используй агента в Claude Code
Открой Claude Code и в чате:

```
[вставь весь текст из AGENT_PROMPT.md]

Теперь выполни: Покажи мне что в permission_denied за последние 24 часа
```

Агент сразу поймёт что он может делать и выполнит задачу автоматически.

## Полный процесс с объяснением

### 1. Подготовка окружения

```bash
# Открой PowerShell или Bash и перейди в проект
cd C:\ChaikaUA\mobile-app-short

# Запусти админ-панель (один из способов)
npm run dev --prefix admin-panel

# ИЛИ используй готовый скрипт
.\start-admin-panel.bat

# ИЛИ PowerShell
powershell -ExecutionPolicy Bypass -File .\start-admin-panel.ps1
```

**Ожидаемый вывод:**
```
▲ [VITE] v7.3.3  ready in 390 ms

➜  Local:   http://localhost:5174/
```

### 2. Логин в админ-панель

1. Открой браузер → `http://localhost:5174/#dashboard`
2. Нажми **"Войти через Google"**
3. Выбери аккаунт (должен быть создан в Firebase как admin)
4. Должны появиться метрики системы

**Если ошибка "permission_denied":**
- Проверь что ты добавлен как администратор в Firebase
- Проверь правила Firebase: `/security_config/authorized_admins`

### 3. Подготовка промта

**Способ А: Копипаст (рекомендуется)**
1. Открой `AGENT_PROMPT.md`
2. Ctrl+A → Ctrl+C (скопируй всё)
3. Открой Claude Code (или ChatGPT)
4. Новый чат
5. Ctrl+V (вставь промт в самом начале)
6. Напиши свою задачу

**Способ Б: Прямая ссылка**
Если используешь Claude Code web, можешь создать закладку:
```
file:///C:/ChaikaUA/mobile-app-short/ЗАПУСК АПК/--Bot-Ai-Klienti/AGENT_PROMPT.md
```

### 4. Примеры команд для агента

Скопируй промт выше, потом напиши одну из:

```
1️⃣ Быстрая диагностика:
"Агент, проверь permission_denied за 24ч и скажи главные проблемы"

2️⃣ Полная проверка системы:
"Агент, дай полный отчёт: dashboard метрики, error monitor, security status"

3️⃣ Модерация контента:
"Агент, покажи мне всё что ждёт в модерации (фото, заявки, объявления)"

4️⃣ Управление системой:
"Агент, включи maintenance mode на 2 часа"

5️⃣ Мониторинг:
"Агент, проверяй каждые 30 минут permission_denied и пиши мне если > 25"
```

## Troubleshooting

### ❌ "Port 5174 is already in use"
```bash
# Найди какой процесс занимает порт
netstat -ano | findstr :5174

# Убей процесс (замени PID на число из вывода выше)
taskkill /PID 12345 /F

# Запусти заново
npm run dev --prefix admin-panel
```

### ❌ "Firebase permission denied"
Проверь в Firebase Console:
1. Security Rules → Database Rules
2. Убедись что путь `/security_config` доступен для authenticated users
3. Проверь `/security_config/authorized_admins` — твой UID там?

### ❌ Агент не видит админ-панель
1. Панель должна быть на `http://localhost:5174` (не https!)
2. Убедись что панель загружена: открой в браузере, должна быть форма входа
3. Залогинься через Google перед тем как просить агента что-то делать

### ❌ Таблица permission_denied не открывается
1. На Dashboard должна быть карточка "permission_denied 24ч"
2. Если число = 0 → кнопка не видна (нет ошибок)
3. Если число > 0 → кнопка "Показать подробности" видна
4. Кликни на кнопку → откроется таблица

## Для разработчиков

### Как агент управляет админ-панелью?

Агент использует **agent-browser** CLI:
```bash
# Открыть страницу
agent-browser open "http://localhost:5174/#dashboard"

# Получить структуру страницы
agent-browser snapshot

# Кликнуть на элемент
agent-browser click @e42

# Заполнить форму
agent-browser fill @e1 "текст"

# Снять скриншот
agent-browser screenshot result.png
```

Агент видит HTML структуру, находит нужные элементы по ref-номерам и кликает на них.

### API для кастомизации

Если ты хочешь добавить новые страницы в админ-панель:

1. **Добавь в `/admin-panel/src/pages/`** новый компонент
2. **Зарегистрируй в AppShell** (навигация)
3. **Скажи агенту в промте:** какие URL и какие элементы там есть
4. **Агент будет использовать** agent-browser для взаимодействия

Пример новой страницы:
```tsx
// CustomAnalyticsPage.tsx
export const CustomAnalyticsPage = () => {
  return (
    <section>
      <h2>Custom Analytics</h2>
      <button id="export-btn">Export data</button>  ← agent-browser сможет кликнуть
      <div id="chart">...</div>
    </section>
  );
};
```

## 📞 Поддержка

Если что-то не работает:

1. **Проверь логи админ-панели:**
   ```bash
   # В терминале где запущена панель, смотри консоль
   # Должны быть только warning'и о Fast Refresh
   ```

2. **Проверь консоль браузера:**
   - F12 → Console
   - Не должно быть красных ошибок
   - Жёлтые warning'и — нормально

3. **Перезагрузи панель:**
   - Ctrl+C в терминале (остановить сервер)
   - `npm run dev --prefix admin-panel` (запустить заново)
   - Ctrl+Shift+R в браузере (hard refresh)
