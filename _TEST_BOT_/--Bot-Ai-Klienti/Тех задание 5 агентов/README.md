# Тех задание: 5 AI-агентов для создания заявок как обычные пользователи

## Главная цель

Создать заявки в мобильном приложении Chaika Life от имени тестовых бот-аккаунтов и отправить их на обычную модерацию так, как это делает живой пользователь.

AI-агенты не имеют прав администратора, не обходят модерацию, не меняют приложение, не меняют сервер, не меняют правила Firebase и не используют прямую запись в базу данных.

## Абсолютные запреты

Запрещено выполнять любые действия, которые изменяют приложение, серверную часть или правила доступа.

Нельзя:

- редактировать код мобильного приложения;
- редактировать код админ-панели;
- редактировать Firebase rules;
- менять RTDB rules, Storage rules или Auth settings;
- менять `firebase.rules.json`;
- менять `admin-panel/src/services/authService.ts`;
- менять `admin-panel/src/firebase/firebase.ts`;
- менять любую логику `user_roles`, `security_config`, `authorized_devices`, `invite_access`;
- запускать скрипты, которые создают, удаляют или изменяют пользователей;
- запускать `scripts/seed-bot-users.mjs` без отдельного прямого разрешения владельца;
- писать заявки напрямую в Firebase RTDB;
- использовать Firebase Admin SDK для создания заявок;
- использовать REST API Firebase для прямой записи заявок;
- выдавать себе права администратора, модератора или владельца;
- менять статус заявки вручную;
- обходить очередь модерации;
- публиковать заявку сразу со статусом `approved`, если приложение само не делает это штатно;
- использовать админ-панель для одобрения своих заявок;
- менять пароль, email, UID, профиль или доступ бот-аккаунтов;
- удалять или редактировать существующие заявки других пользователей;
- делать любые действия, которые обычный пользователь не может сделать через интерфейс приложения.

Если для выполнения задачи требуется изменить код, правила, базу данных, роли, доступы или админ-панель, агент обязан остановиться и запросить разрешение у владельца.

## Разрешенные действия

AI-агенту разрешено только:

- открыть мобильное приложение Chaika Life;
- войти под одним из тестовых бот-аккаунтов через обычный экран входа;
- пользоваться приложением только через пользовательский интерфейс;
- создать заявку через штатную кнопку добавления заявки;
- заполнить поля заявки вручную как обычный пользователь;
- прикрепить фото только если это доступно обычному пользователю и не обязательно для заявки;
- нажать штатную кнопку публикации или отправки;
- дождаться, пока заявка уйдет на модерацию обычным способом;
- зафиксировать результат: аккаунт, категория, заголовок, текст, время отправки, видимый статус;
- выйти из аккаунта и повторить процесс под другим ботом.

## Правило поведения как живой пользователь

Каждая заявка должна выглядеть как реальное сообщение от жильца или локального специалиста.

Требования к тексту:

- писать естественно, без признаков автоматической генерации;
- не писать, что сообщение создано AI;
- не писать технические данные Firebase, UID, RTDB, rules, токены или внутренние пути;
- не просить модератора обойти правила;
- не использовать агрессивный, рекламный, спамный или конфликтный тон;
- не публиковать персональные данные реальных людей;
- не указывать реальные чужие телефоны, адреса, документы или фотографии;
- писать конкретно: что нужно, где примерно, когда актуально, как откликнуться через приложение;
- не обещать невозможное;
- не создавать опасные медицинские, юридические или финансовые инструкции;
- не публиковать запрещенный, политический, дискриминационный или мошеннический контент.

## Порядок работы каждого агента

1. Выбрать назначенного бота.
2. Открыть приложение Chaika Life.
3. Войти через обычный экран входа по email и паролю.
4. Проверить, что открыт обычный пользовательский интерфейс.
5. Перейти к созданию заявки через штатную кнопку `+`, `Додати`, `Создать` или аналогичную.
6. Выбрать подходящую категорию.
7. Заполнить заголовок и описание.
8. Проверить текст на естественность, безопасность и отсутствие технических данных.
9. Нажать штатную кнопку отправки или публикации.
10. Убедиться, что заявка отправлена на модерацию или появилась в пользовательском статусе, предусмотренном приложением.
11. Записать результат в отчет.
12. Выйти из аккаунта, если нужно передать устройство следующему агенту.

## Шаблон заявки

Использовать шаблон только как основу. Текст нужно адаптировать под выбранного бота и категорию.

```text
Заголовок: Коротко описать суть заявки

Описание:
Добрый день. Нужна помощь/хочу предложить помощь/заметил проблему в районе Чайка, корпус 1.

Суть: описать ситуацию в 1-3 предложениях.
Когда актуально: сегодня / завтра / на этой неделе / в удобное время.
Где примерно: двор / подъезд / рядом с корпусом / без точного адреса.
Как откликнуться: через приложение или комментарий к заявке.
```

```text

Дата и время отправки:
Категория:
Заголовок:
Краткое описание:
Фото: да/нет
Видимый статус после отправки:
Была ли заявка отправлена через обычный UI: да
Были ли изменения кода/правил/базы: нет
Проблемы или ошибки:
```

## Критерий успешного выполнения

Задача считается выполненной только если:

- заявка создана через обычный пользовательский интерфейс приложения;
- использован тестовый бот-аккаунт;
- заявка отправлена на штатную модерацию или получила штатный пользовательский статус;
- не было изменений кода приложения;
- не было изменений Firebase rules;
- не было прямой записи в Firebase;
- не было использования админских прав;
- не было обхода модерации;
- отчет по заявке заполнен.

## Если что-то не работает

Если бот не входит, заявка не отправляется, приложение показывает ошибку или требуется доступ выше обычного пользователя, агент должен остановиться.

Разрешено сообщить владельцу:

```text
Не удалось выполнить действие через обычный пользовательский интерфейс. Требуется проверка владельцем. Я не менял код, правила, базу данных и не обходил модерацию.
```

Запрещено самостоятельно исправлять это через код, Firebase, правила, админ-панель или прямую запись в базу.
